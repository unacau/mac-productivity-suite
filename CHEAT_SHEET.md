# Mac Productivity Suite: Cheat Sheet

This document lists all the active Hyper Key (`Caps Lock` held) shortcuts for the Mac Productivity Suite.

## Core Modifiers
| Key Action | Result |
| :--- | :--- |
| **Hold `Caps Lock`** | **Hyper Key** (`Cmd + Opt + Ctrl + Shift`) |
| **Tap `Caps Lock`** | **Escape** |

---

## Global Application Switcher
Press **Hyper + Key** to launch or focus the corresponding application.

### Primary Apps
- `Hyper + T`: **Terminal**
- `Hyper + S`: **Safari**
- `Hyper + B`: **Brave Browser**

### Productivity & Web Apps (Standalone)
- `Hyper + M`: **TextMate**
- `Hyper + L`: **Telegram**
- `Hyper + D`: **SoundCloud** (Standalone Safari App)
- `Hyper + P`: **Spotify** (Standalone Safari App)

### System Apps
- `Hyper + F`: **Finder**
- `Hyper + H`: **Photos**
- `Hyper + N`: **Notes**
- `Hyper + R`: **Reminders**
- `Hyper + C`: **Calendar**

---

## Terminal Features
- **Copy on Select**: Highlighting text in the native macOS Terminal automatically copies it to the clipboard.
- **Robustness**: Uses a 100ms delay to ensure the OS registers the selection before copying.
